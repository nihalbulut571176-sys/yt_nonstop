# Remotion FastGen First120 Prototype

This directory contains the lightweight in-repo Remotion prototype for the first 120 seconds of the `illyuziya_vybora` workflow.

Included:
- `package.json`
- `remotion/entry.jsx`
- `remotion/index.jsx`
- `remotion/fastgenFirst120Data.js`
- `notes/alignment_note.md`
- `notes/remotion_prompts_first_120_seconds.md`

Excluded on purpose:
- `node_modules`
- rendered videos
- generated PNG assets
- local audio / public media payloads

## Purpose

This prototype captures:
- the composition structure
- scene timing and first-120 sequence thinking
- the motion-graphics direction layered on top of still-image workflow outputs

It is a source artifact for the future web app, not a finished product.
